## Why Bitcore Wallet
| Feature | |
|---|---|
| Self-custody | You hold the keys and the recovery phrase |
| Multisig | Shared control across several keys |
| Watch-only | Check balances without keys |
| Fee control | Choose speed vs cost |
| Free to install | Only network fees apply |
| Open-source foundation | Built on the Bitcore platform |

Read more on the website: [security](https://bitcorewallet.org/security), [multisig](https://bitcorewallet.org/multisig) and [fees](https://bitcorewallet.org/fees).
